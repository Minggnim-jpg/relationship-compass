本文件描述单个对象的罗盘和记录格式。涉及任何档案读取或写入前，先遵循 [multi-person-records](multi-person-records.md)。下文 profile.md、timeline.md、compass.md、config.md、sessions/ 均相对于已选对象目录；旧 compass-data/ 文件树仅作为历史格式参照，不再作为默认存储位置。

事实与 AI 推测必须分栏。评分是启发式估计，不是喜欢概率或科学测量；证据不足标记未知，不用初始化的 50% 当成事实。

## 关系罗盘 ⭐

**目的**：实时可视化关系状态，在用户明确要求记录/更新互动后更新。

### 7维罗盘

| 维度 | 定义 | 计算方式 | 更新时机 |
|------|------|----------|----------|
| **热度** | 她对你的兴趣程度 | 主动、暧昧、分享、回应质量 | 每次记录互动后 |
| **互惠度** | 双方投入是否有来有回 | 你主动/她主动、你付出/她回应 | 每周统计 |
| **安全感** | 她靠近你时是否放心 | 稳定回应、信任、情绪舒适度 | 每次记录互动后 |
| **边界清晰度** | 关系边界和身体/情绪边界是否清楚 | 是否尊重拒绝、是否过度模糊 | 每次记录互动后 |
| **场域压力** | 外部环境对关系的约束 | 工作、同事、现任/前任、身份风险 | 关键事件后 |
| **风险** | 关系崩坏/操控/失衡风险 | 操控痕迹+边界触碰+场域压力 | 每次记录互动后 |
| **趋势** | 变化方向 | 与上周对比 | 每周日 |

### 显示格式

```markdown
## 关系罗盘 (YYYY-MM-DD 更新)

| 维度 | 当前值 | 趋势 | 判断 |
|------|--------|------|------|
| 热度 | XX% | ↘/→/↗ | 状态判断 |
| 互惠度 | 你XX%/她XX% | ↘/→/↗ | 是否有来有回 |
| 安全感 | 低/中/高 | ↘/→/↗ | 是否稳定、可回应、可靠 |
| 边界清晰度 | 模糊/基本清晰/清晰 | ↘/→/↗ | 是否尊重边界 |
| 场域压力 | 低/中/高 | ↘/→/↗ | 外部约束强度 |
| 风险 | 低/中/高 | ↘/→/↗ | 需注意什么 |
| 趋势 | ↘降温/→稳定/↗升温 | — | 综合方向 |

**综合判断**：一句话总结当前状态 + 下一步建议
```

### 维度判断标准

**热度**：
- 80%+：她主动约、主动暧昧、明显在意
- 60-80%：维持联系、偶尔主动、有暧昧但不推进
- 40-60%：回复但被动、暧昧减少、开始降温
- <40%：回复变慢、回避暧昧、明显冷淡

**互惠度**：
- 你<50%/她>50%：她更主动，你需要稳住但不要过冷
- 你50%/她50%：平衡，共同推进
- 你>50%/她<50%：开始失衡，减少单向供给
- 你>70%/她<30%：严重失衡，停止追逐，观察她是否回流

**安全感**：
- 高：她愿意靠近、表达真实情绪、互动后不明显后撤
- 中：她愿意互动，但推进时会收、需要空间
- 低：她紧张、回避、抗拒明确推进，或你表现不稳定

**边界清晰度**：
- 清晰：能表达需求和拒绝，双方都尊重
- 基本清晰：大体尊重边界，但关系定义仍有模糊
- 模糊：暧昧、付出、身体边界或关系期待长期不清楚

**场域压力**：
- 低：外部约束少，互动主要由双方意愿决定
- 中：有工作、同事、距离、情绪状态等限制
- 高：已有伴侣、办公室风险、公开评价、重大压力强烈影响互动

**风险**：
- 低：自然互动、互惠存在、边界被尊重、场域压力可控
- 中：投入失衡、边界模糊、场域压力上升、出现操控痕迹
- 高：明确拒绝仍纠缠、身体/情绪边界被触碰、煤气灯/三角测量/冷暴力明显

## 按需保存机制 ⭐

**触发时机**：仅当用户明确要求「记录」「更新罗盘」「保存这次互动」等写入动作时，执行以下步骤。

### 记录流程

```
用户要求记录互动 → 我提取信息 → 更新3个文件
```

### Step 1: 信息提取

从用户描述中提取：
- **日期**：今天/昨天/具体日期
- **事件**：互动内容摘要
- **她的信号**：主动/被动/暧昧/回避（哪个信号类型）
- **你的策略**：使用了哪个关系动力模型
- **效果评估**：成功/无效/待观察
- **罗盘变化**：热度、互惠度、安全感、边界清晰度、场域压力、风险、趋势的变化

### Step 2: 更新 timeline.md

**追加格式**：
```markdown
### YYYY-MM-DD
- [事件摘要]
- 她的信号：[信号类型]
- 你的策略：[使用的模型]
- 效果：[评估结果]
```

### Step 3: 更新 compass.md

**更新方式**：
1. 读取当前 compass.md
2. 如果 compass.md 仍是旧字段（投入度/位置感/信号数），先迁移为新7维罗盘
3. 根据本次互动调整各维度值
4. 更新趋势箭头
5. 更新综合判断
6. 更新日期戳

**旧罗盘迁移规则**：
- 投入度 → 互惠度
- 位置感 → 并入互惠度判断与综合判断
- 信号数 → 并入热度证据与历史记录
- 新增安全感、边界清晰度、场域压力，基于 profile.md、timeline.md 和最近 sessions 估算，并标注「待校准」

### Step 4: 创建 sessions/ 详细记录

**文件名**：`sessions/<保存时间>-<uuid>.md`，按 multi-person-records 生成唯一文件名；事件关键词放在标题中。

**内容模板**：
```markdown
# Session: YYYY-MM-DD [事件关键词]

## 摘要
[一句话描述本次互动]

## 她的信号
- [信号1] (+X分)
- [信号2] (+X分)
- [信号3] (+X分)

## 你的策略
- 使用模型：[关系动力模型名称]
- 具体执行：[你怎么做的]
- 是否遵循禁忌：[检查结果]

## 效果评估
- [成功/无效/待观察]
- [具体分析]

## 罗盘更新
| 维度 | 变化 | 新值 |
|------|------|------|
| 热度 | ±X% | XX% |
| 互惠度 | ±X% | 你XX%/她XX% |
| 安全感 | 低/中/高变化 | 低/中/高 |
| 边界清晰度 | 变化说明 | 模糊/基本清晰/清晰 |
| 场域压力 | 低/中/高变化 | 低/中/高 |
| 风险 | ±X | 低/中/高 |

## 下次建议
[下次遇到类似场景的建议]
```

## 挥久化机制

记录关系演进，持续优化策略。详情见项目目录。

### 文件结构

```
compass-data/
├── profile.md        # 她的基本信息（手动维护）
├── timeline.md       # 关系演进时间线（按需+手动）
├── compass.md        # 关系罗盘（按需更新）⭐
├── config.md         # 你的设置和偏好（手动维护）
└── sessions/         # 每次互动的详细记录（按需生成）⭐
    ├── 2026-04-09-初次使用.md
    ├── 2026-04-10-聊天.md
    └── ...
```

### 使用方式

1. **首次**：创建 `profile.md` + `config.md` + `compass.md`（初始化罗盘）
2. **用户要求记录互动后**：更新 timeline.md + compass.md + 创建 sessions/ 详细记录 ⭐
3. **重要互动**：用户要求保存时，sessions/ 生成详细记录 ⭐
4. **定期回顾**：读取 compass.md 查看罗盘状态，读取 timeline.md 分析模式

### compass.md 初始化模板

```markdown
# 关系罗盘

## 当前状态 (YYYY-MM-DD)

| 维度 | 当前值 | 趋势 | 判断 |
|------|--------|------|------|
| 热度 | 未知 | — | 待提供互动证据 |
| 互惠度 | 未知 | — | 待提供双方投入记录 |
| 安全感 | 未知 | — | 待提供互动证据 |
| 边界清晰度 | 未知 | — | 待提供互动证据 |
| 场域压力 | 未知 | — | 待提供现实背景 |
| 风险 | 未知 | — | 待提供互动证据 |
| 趋势 | 未知 | — | 尚无历史可比较 |

**综合判断**：关系初始状态，需要通过互动积累数据。

---

## 热度计算规则

| 她的行为 | 加分 |
|----------|------|
| 主动找你（微信/飞书） | +5 |
| 主动约你 | +10 |
| 主动暧昧梗 | +3 |
| 分享生活/照片 | +2 |
| 回复快且热情 | +2 |
| 回复慢且冷淡 | -3 |
| 回避暧昧 | -5 |
| 明确拒绝 | -10 |

---

## 互惠度计算规则

| 行为 | 记录 |
|------|------|
| 你主动找她/延续话题 | 你+1 |
| 她主动找你/延续话题 | 她+1 |
| 你主动约她/安排见面 | 你+2 |
| 她主动约你/安排见面 | 她+2 |
| 你单向照顾/解释/安抚 | 你+1 |
| 她主动照顾/解释/安抚 | 她+1 |

每周统计：你主动次数 vs 她主动次数 → 计算百分比

---

## 安全感评估规则

| 信号 | 影响 |
|------|------|
| 她主动分享真实情绪 | + |
| 她靠近后不明显后撤 | + |
| 你稳定回应，不追问、不施压 | + |
| 你情绪化、追问、施压 | - |
| 她推进时明显紧张或回避 | - |

---

## 边界清晰度评估规则

| 信号 | 影响 |
|------|------|
| 双方能表达拒绝和需求 | 清晰 |
| 身体边界被尊重 | 清晰 |
| 关系期待长期不说破 | 模糊 |
| 付出和回报长期不对称但无人承认 | 模糊 |
| 明确拒绝后仍继续推进 | 高风险 |

---

## 场域压力评估规则

| 压力源 | 影响 |
|--------|------|
| 同事/办公室关系 | 中-高 |
| 现任/前任/暧昧对象 | 中-高 |
| 工作压力、裁员、出差 | 中 |
| 公开评价、朋友圈层重叠 | 中 |
| 时间距离、城市距离 | 低-中 |

---

## 风险评估规则

| 风险因素 | 累计值 |
|----------|--------|
| 过度使用间歇强化（被感知） | +20 |
| 她开始怀疑「你是不是在玩我」 | +30 |
| 互惠度严重失衡（你>70%） | +15 |
| 触碰禁忌（爹味/炫耀/死皮赖脸） | +25 |
| 被明确质疑策略 | +40 |
| 身体/情绪边界被触碰 | +40 |
| 场域压力高但继续强推 | +25 |

风险等级：
- 0-30：低
- 31-60：中
- 61+：高
```
