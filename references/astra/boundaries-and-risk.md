## 反操控检测清单

详情见 `references/research/06-counter-manipulation.md`。

### 6种操控策略

| 策略 | 识别信号 |
|------|---------|
| 间歇强化 | 忽冷忽热，你追她冷，你放弃她出现 |
| 模糊边界 | 不定义关系，「我们不是朋友吗」 |
| 三角测量 | 提及其他追求者，制造竞争感 |
| 叙事重构 | 「我又没让你这样」，你的付出被定义为自愿 |
| 示弱控制 | 「都是我不好」「我配不上你」，制造愧疚感 |
| 煤气灯效应 | 「你记错了」「你想多了」，否认你的感知 |

### 检测问题

```
问自己：
1. 在这段关系中，我是付出更多的一方吗？
2. 她的热度与我付出成反比吗？
3. 她有没有正面回应过「你喜欢我吗」？
4. 当我停止主动，她会主动吗？
5. 她有没有说过「我又没让你这样」？
6. 我在这段关系中感到焦虑、不确定吗？
7. 我的情绪跟着她起伏吗？
8. 我有没有因为怕失去她而放弃原则？

多个「是」= 可能被操控。
```

## 价值观与诚实边界

### 这个框架追求的

1. **理解人际动力学**——看清真实权力结构
2. **提升吸引力**——建立真实价值，不是演戏
3. **策略自觉**——知道自己在做什么，不是无意识操控
4. **攻防兼备**——既能建立吸引力，也能识别操控

### 这个框架拒绝的

- **无差别伤害**——对真心待你好的人用操控策略
- **自我欺骗**——把策略当成真实情感
- **上瘾式使用**——把策略当成唯一社交方式
- **道德优越感**——觉得「看穿一切」就高人一等

### 内在矛盾

1. **控制 vs 真情**——精密计算的背后，有时候自己也分不清哪些是策略哪些是真心
2. **短期有效 vs 长期代价**——间歇强化短期内极其有效，但长期会耗尽信任储备
3. **自由 vs 孤独**——不定义关系保留了自由，但也意味着没有人真正「属于」你

### 局限性声明

- 这是分析工具，不是行为指南。目的是提升认知，不是鼓励操控
- 模型是简化。现实中的人际互动比任何模型复杂
- 文化局限：主要基于中文互联网语境，其他文化适用性有限
- 心理健康边界：如果行为模式造成真实困扰，建议寻求专业心理咨询
