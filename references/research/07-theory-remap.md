# 理论重映射：从旧7模型到8个关系动力模型

## 为什么重映射

旧版 7 个模型更偏短期暧昧和拉扯策略：间歇强化、模糊边界、价值锚定、叙事重构、节奏控制、情绪价值、竞争感。

这些模型能解释一部分吸引力和位置感，但它们不是 Skinner、Bowlby、Cialdini、Festinger、Lewin、Kahneman/Tversky 等理论本身自然推出的完整框架。它们更像把理论中的一部分机制包装成了恋爱策略。

新版改为 8 个关系动力模型，目标是同时覆盖：
- 吸引
- 安全感
- 互惠
- 边界
- 场域压力
- 得失判断
- 长期信任
- 操控风险识别

---

## 新8模型

| 模型 | 主要来源 | 核心问题 |
|------|----------|----------|
| 反馈强化模型 | Skinner 强化理论 | 什么行为被回应、奖励或冷处理？ |
| 安全基地模型 | Bowlby 依恋理论 | 你是否稳定、可回应、可靠？ |
| 未完成张力模型 | Zeigarnik 效应 | 哪些悬而未决的事在占据注意力？ |
| 互惠与影响模型 | Cialdini 影响力原则、社会交换理论 | 双方是否有来有回？ |
| 认知一致性模型 | Festinger 认知失调、归因理论 | 双方如何解释自己的行为？ |
| 场域压力模型 | Lewin 场论 | 环境、身份、第三方如何影响行为？ |
| 得失参照模型 | Kahneman/Tversky 前景理论 | 谁更怕失去？参照点是什么？ |
| 信任修复模型 | 依恋理论、关系维护研究 | 冲突后能否修复和恢复连接？ |

---

## 旧模型如何降级使用

| 旧模型 | 新位置 | 使用方式 |
|--------|--------|----------|
| 间歇强化引擎 | 反馈强化模型 + 反操控检测 | 用来识别忽冷忽热循环，不默认建议制造忽冷忽热 |
| 模糊边界法则 | 未完成张力模型 | 用来判断悬置状态，不把长期不定义当默认策略 |
| 价值锚定 | 互惠与影响模型 + 得失参照模型 | 用来稳定自我价值和投入比例，不用于炫耀或压迫 |
| 叙事重构术 | 认知一致性模型 | 用来分析解释权和自我合理化，不用于抹掉感谢或套取付出 |
| 节奏控制 | 反馈强化模型 + 场域压力模型 | 用来校准推进速度，不用于冷暴力 |
| 情绪价值引擎 | 安全基地模型 + 互惠与影响模型 | 用来提升相处质量，但不能替代真实价值和公平 |
| 竞争感制造 | 得失参照模型 + 反操控检测 | 用来识别损失厌恶和三角测量，不建议故意制造嫉妒 |

---

## 输出原则

1. 先判断事实，再给推断。
2. 先看安全感、互惠、边界，再看吸引和张力。
3. PUA/操控性材料优先用于识别风险和改写表达，不直接复制执行。
4. 明确拒绝、身体边界、现实关系约束优先级高于任何模型。
5. 如果模型解释和现实反馈冲突，以现实反馈为准。

---

## 核心公式

旧版：

```text
吸引 = 不确定性 + 价值感 + 节奏 + 情绪价值 + 竞争感
```

新版：

```text
关系动力 = 吸引 + 安全感 + 互惠 + 边界 + 场域压力 + 得失判断 + 长期信任
```
