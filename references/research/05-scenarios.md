# 典型场景与关系动力策略

## 场景分类

```text
初识 → 暧昧 → 升温 → 瓶颈 → 危机 → 维护
```

场景判断必须先看 7 维关系罗盘：

- 热度
- 互惠度
- 安全感
- 边界清晰度
- 场域压力
- 风险
- 趋势

---

## 初识阶段

**目标**：建立轻松、真实、可继续的第一印象。

**策略**：

| 维度 | 行动 |
|------|------|
| 形象 | 干净、整洁、有基本审美 |
| 交流 | 自然接话，不面试式追问 |
| 安全感 | 不压迫、不油腻、不越界 |
| 互惠 | 自我暴露和提问保持平衡 |

**常见错误**：
- 上来就查户口
- 炫耀履历、资源、见识
- 急于证明自己有趣
- 对方冷淡还继续强行推进

**关键动作**：
1. 找到共同话题
2. 用「状态 + 感受」表达自己
3. 用观察式表达代替审问式提问
4. 在对话自然变淡时体面收住

---

## 暧昧阶段

**目标**：在不压迫对方的前提下，让关系有情绪温度和持续互动。

**判断暧昧的标准**：
- 互动频率高于普通朋友
- 她会主动找你或延续话题
- 有只属于你们的梗、默契或轻微情绪张力
- 她愿意分享生活、情绪或私人判断

**策略**：

| 关系动力模型 | 应用 |
|--------------|------|
| 反馈强化模型 | 看什么互动让她更愿意靠近，不奖励冷淡为你的加倍付出 |
| 安全基地模型 | 让她感觉你稳定、可回应、不急着索取 |
| 互惠与影响模型 | 保持有来有回，不单向输出情绪价值 |
| 未完成张力模型 | 保留轻微余味，但不长期吊着、不逃避清晰表达 |

**推进信号**：
- 她主动约你或创造见面机会
- 她主动分享更私人的信息
- 她主动延续你们的梗
- 她开始关心你的状态和安排

**推进方式**：
- 情感进阶：从事实分享进入感受分享
- 未来进阶：提出轻量、具体、低压力的下次活动
- 边界进阶：任何身体接近都以对方舒适和明确反馈为前提

---

## 升温阶段

**目标**：让关系从轻暧昧进入更稳定、更互惠的连接。

**策略**：

| 维度 | 行动 |
|------|------|
| 热度 | 回应她的主动，不泼冷水 |
| 互惠度 | 她主动时你接住，你主动时观察她是否接住 |
| 安全感 | 关键时刻稳定，不让她猜你是不是在玩 |
| 边界清晰度 | 关系期待开始变强时，避免长期模糊 |
| 场域压力 | 同事、现任/前任、公开评价存在时，降低强推 |

**判断她准备好**：
- 她主动提未来安排
- 她主动表达在意
- 她对你的缺席有反应
- 她愿意承担一部分推进责任

**推进时机**：
- 互动自然、轻松、互惠时
- 她释放明确靠近信号时
- 场域压力可控时

**不要推进的时机**：
- 她明显疲惫、焦虑、压力大
- 她刚表达拒绝或收回边界
- 场域压力高且没有私密安全空间

---

## 瓶颈阶段

### 她冷淡了

**诊断**：

| 可能原因 | 判断方式 |
|----------|----------|
| 需要空间 | 之前推进过快，或她靠近后开始收 |
| 热度下降 | 长期不主动、不延续、回应质量下降 |
| 场域压力上升 | 工作、他人关系、现任/前任、公开环境影响 |
| 互动失衡 | 你输出多，她回应少 |
| 操控循环 | 她只在你要离开时短暂靠近 |

**应对策略**：
1. 暂停追问和加码。
2. 保持正常生活和稳定可见。
3. 降低单向输出，观察她是否回流。
4. 如果持续冷淡，接受现实，不用解释成复杂策略。

**关键**：
- 不连续发消息追问
- 不用冷暴力惩罚
- 不把一次冷淡过度解读成关系终局
- 观察事实，不靠脑补补剧情

---

### 她犹豫不决

**表现**：
- 有靠近，也有后撤
- 接暧昧，但不承担推进
- 你退一步，她会拉一下；你进一步，她又收

**诊断**：
- 她可能有兴趣但场域压力大
- 她可能需要安全感
- 她可能享受模糊但不愿承担关系责任

**应对策略**：
1. 给空间，不逼迫即时表态。
2. 看互惠度，而不是只看热度。
3. 设置自己的时间和情绪边界。
4. 如果长期模糊，温和表达你的真实期待。

**表达示例**：

```text
我挺喜欢现在的相处
但我也不想一直靠猜
我们可以慢一点 但最好真实一点
```

---

### 关系停滞

**表现**：
- 互动稳定但没有新鲜感
- 双方都不推进
- 话题变成例行打卡

**应对策略**：
1. 增加真实生活内容，而不是硬找话题。
2. 用新活动、新场景带来新信息。
3. 尝试一次低压力邀约。
4. 如果她不响应，降低投入，回到普通互动。

---

## 危机处理

### 她质疑你

**常见质疑**：
- 「你是不是对每个人都这样」
- 「你是不是只是想玩玩」
- 「我觉得你不太认真」

**应对原则**：
- 不急着自证
- 不反讽、不甩锅
- 承认她的感受，再表达你的边界和真实态度

**应对示例**：

```text
你会这么想也正常
可能我有些表达确实容易让人误会
但我不是随便玩玩
如果哪里让你不舒服 你可以直接说
```

---

### 她后退了

**可能原因**：
- 你推进太快
- 她需要空间
- 场域压力上升
- 她发现边界不舒服
- 她兴趣下降

**应对策略**：
1. 停止推进。
2. 给空间。
3. 保持稳定，不用焦虑感压她。
4. 她回来时正常接住，不翻旧账。
5. 她不回来时接受事实。

---

### 她明确拒绝

**应对原则**：
- 不纠缠
- 不争辩
- 不索要解释
- 保留体面

**应对示例**：

```text
明白
谢谢你直接说
我会尊重你的想法
```

---

## 关系维护

**目标**：维持吸引、互惠、安全感和边界清晰度。

| 维度 | 行动 |
|------|------|
| 保持自我 | 不因为关系放弃朋友、爱好和事业 |
| 持续新鲜 | 一起经历新事情，而不是只聊天 |
| 情绪价值 | 让她跟你相处轻松、被理解 |
| 互惠公平 | 不长期单向供给，也不长期单向索取 |
| 信任修复 | 有误会时能解释、道歉、调整 |

**常见错误**：
- 确认关系后冷淡
- 只谈感受，不处理现实问题
- 把边界清晰误解成失去吸引
- 把长期关系经营当成短期拉扯

---

## 特殊场景

### 她有男朋友/正在接触其他人

**原则**：
- 不破坏他人关系
- 不做备胎
- 不以竞争感刺激她
- 她主动靠近时，也要看边界和现实约束

**策略**：
1. 保持友好但不越界。
2. 不主动制造暧昧压力。
3. 如果她释放靠近信号，先确认边界。
4. 如果她长期模糊，退出三角关系。

---

### 异地/线上为主

**挑战**：
- 缺乏线下真实反馈
- 容易变成聊友
- 容易用脑补填空

**策略**：
| 策略 | 说明 |
|------|------|
| 提升单次交流质量 | 少一点流水账，多一点真实感受 |
| 创造低压力见面机会 | 有条件时从线上转线下 |
| 观察互惠度 | 她是否也主动安排和延续 |
| 避免情绪透支 | 不把线上聊天当全部关系 |

---

### 她忽冷忽热

**诊断**：
- 可能是压力或回避
- 可能是兴趣不稳定
- 可能是互惠失衡
- 也可能是操控循环

**应对策略**：
1. 不被她的节奏牵着情绪走。
2. 她热时正常回应，不立刻加码。
3. 她冷时不追问、不补偿式付出。
4. 记录模式：多久冷、多久回、回来的质量如何。
5. 如果长期循环，设定边界并降低投入。

---

## 场景决策树

```text
她在做什么？
├── 热情、主动
│   └── 接住主动，观察互惠是否持续
├── 平淡、例行
│   └── 增加真实生活内容，尝试低压力新场景
├── 冷淡、后撤
│   └── 停止追问和加码，观察是否回流
├── 犹豫、摇摆
│   └── 给空间，同时设定自己的时间和情绪边界
├── 明确拒绝
│   └── 尊重拒绝，体面退场
└── 场域压力高
    └── 降低推进，优先边界和现实约束
```
