# NotebookLM 聊天沟通技巧参照库

## 可选配置

本项目不附带私有笔记本或账号配置。只有用户明确指定其有权访问的 NotebookLM 笔记本，且宿主提供对应工具时，才使用该扩展。未配置时使用本地参考资料完成分析，不要求登录或联网。

请将自己的笔记本名称和 ID 保存在公开仓库之外，不要提交到 Git。

---

## 和关系罗盘的分工

`compass` 负责判断关系动力：
- 当前是否适合回复
- 应该轻松、明确、后撤还是推进
- 关系里是否存在互惠失衡、边界模糊、场域压力或风险

NotebookLM 负责提供聊天表达参考：
- 怎么接话
- 怎么延展话题
- 怎么回应情绪
- 怎么表达幽默
- 怎么把干瘪表达改成有画面感的表达
- 怎么把提问改成观察式表达
- 怎么化解尴尬或调侃

---

## 优先使用场景

当用户需要以下能力时，可以查询 NotebookLM：

| 场景 | 查询目的 |
|------|----------|
| 接话 | 找到自然接住对方话头的表达结构 |
| 话题延展 | 使用上堆、下切、平行等方式延长对话 |
| 情绪反馈 | 先接住感受，再决定是否给建议 |
| 自我暴露 | 用自己的经历引导对方打开 |
| 幽默表达 | 把普通回复转成轻松、有画面感的表达 |
| 冷读/观察式表达 | 用观察和猜测代替审问式提问 |
| 框架重组 | 面对质疑、调侃、尴尬时不急着自证 |
| 破冰 | 从陌生或冷场进入自然对话 |
| 回复改写 | 把用户草稿改得更自然、更有边界 |

---

## 使用原则

1. 只抽取结构，不直接照抄原话。
2. 保留用户自己的真实经历和语言风格，不编造假故事。
3. 先由 `compass` 判断关系动力，再用 NotebookLM 辅助表达。
4. 输出回复时优先自然、具体、短、可发送。
5. 对明显操控、打压、欺骗、侵入式推进的内容，只能过滤或改写，不能直接使用。

---

## 禁用方式

不要把 NotebookLM 用作：

- PUA 模式识别库的默认入口
- 原文话术复制库
- 假故事素材库
- 打压或贬低模板库
- 身体推进或边界试探教程
- 为了制造焦虑、嫉妒或不安全感的策略库
