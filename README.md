# 🧭 关系罗盘 · Compass

**简体中文** · [English](README_EN.md)

**帮你看清关系里的位置，想好下一步行动。**

“这句话该怎么回？”很重要。一句合适的回复，可以表达好感、化解误会，也能让关系往前走一步。

但关系怎么发展，更关键的是你们现在的关系状态：双方有多少意愿、投入是否互相回应，以及你接下来实际做了什么。一句漂亮的回复，很难弥补长期的单向付出。

关系罗盘结合具体对话、互动历史和现实处境，帮你判断关系、选择行动，再把想说的话表达清楚。每个对象独立建档，让后续分析有据可循。

**看清关系 → 选择行动 → 组织回复 → 记录和回顾**

## 这些时候，可以打开关系罗盘

| 你在纠结什么 | 它可以帮你做什么 |
|---|---|
| 聊得挺好，但每次约见面都没下文 | 结合聊天和实际行动，梳理可能的解释与下一步 |
| 这句话想回，又怕说得太重 | 保留你的意思和语气，整理成能说出口的话 |
| 总是我主动，是不是投入太多了 | 回看双方投入、回应和反复出现的模式 |
| 每次吵完都和好，同样的问题却一直发生 | 看冲突有没有得到解释、修复和实际调整 |
| 同时在了解几个人，背景和进展容易混 | 为每个对象建立独立档案，分别保存与回顾 |
| 过了一阵子，想知道关系到底有没有变化 | 把新进展与已保存记录对照，查看变化的依据 |

## 它怎么分析关系？

**分析从你提供的材料开始：对话说了什么，实际发生了什么，你希望怎样发展。**

当你要求回顾某个对象时，关系罗盘再结合该对象已经保存的背景、时间线和互动记录。材料里没有的信息，会保留为未知。

它主要从这些角度观察：

| 角度 | 观察什么 |
|---|---|
| **主动与回应** | 谁发起联系、延续话题、提出见面？回应是否落实为行动？ |
| **互惠与投入** | 时间、关心和付出是否有来有回？是否长期由一方维持？ |
| **安全感与信任** | 能否表达真实感受？回应是否稳定？误会后是否愿意修复？ |
| **边界与意愿** | 需求和拒绝是否被尊重？双方期待是否说清楚？ |
| **现实处境** | 工作、距离、已有关系或共同社交圈，是否影响互动？ |
| **反复出现的模式** | 相似的问题是否重复发生？什么行为之后，互动会发生变化？ |
| **变化趋势** | 和之前相比，投入、边界与相处方式有了哪些变化？ |

### 用了哪些分析框架？

Skill 的参考资料整理了以下理论视角，并将它们转成观察关系时的问题。部分历史笔记仍有待核实的概括、数字和经验策略，不应当作已验证的研究结论；核心规则要求优先依据事实、互惠与边界：

| 理论视角 | 在关系分析中怎么用 |
|---|---|
| 依恋与安全基地 | 观察稳定回应、信任，以及靠近和退开的互动 |
| 互惠与社会交换 | 梳理双方投入、期待和失衡的地方 |
| 行为强化 | 观察某种回应是否让一个互动模式反复出现 |
| 归因与认知一致性 | 检查双方如何解释行为，解释与事实是否相符 |
| 场域理论 | 把个人意愿放回工作、距离、身份等实际处境 |
| 未完成效应与得失参照 | 识别悬而未决、害怕失去等因素如何影响判断 |

**这些框架用来提出问题、比较解释。具体建议仍要回到具体证据。** 理论名称不代表这个 Skill 的效果经过科学验证，也不能凭几句话诊断一个人。

分析和记录时，会区分三类内容：

- **已提供的事实**：例如“对方取消了见面”。用户转述会标为转述，不能当作独立核实。
- **可能的解释**：例如“对方可能暂时不想推进”。明确保留为推测。
- **还不知道的事**：例如取消原因、是否愿意重新安排。

罗盘中的评分属于规则估计，不能解释成“对方有 80% 的概率喜欢你”。证据不足时应标记未知。

## 判断之后，下一步怎么做？

关系里的“位置”，指的是双方如何看待这段关系、愿意投入多少，以及对未来的期待是否一致。分析之后，关系罗盘会结合你的目标和对方的反馈，帮你选择具体行动：

- **推进**：双方有意愿时，提出具体、容易回应的邀约，并落实安排。
- **澄清**：期待不一致或长期靠猜时，把自己的需求和疑问说清楚。
- **观察**：信息不足时，明确还需要看什么行动，而不是反复猜一句话。
- **修复或退出**：发生冲突时讨论具体调整；遇到明确拒绝或持续失衡时，尊重边界并调整投入。

回复围绕行动来写。说“我会改”，后面要有实际调整；说“下次见”，后面要有双方愿意落实的安排。

## 看个例子

> 以下为虚构使用示意，展示分析方式；实际回答取决于你提供的信息和所用模型。

**你：**

“认识一个月了，聊天基本都是我先找，对方回复挺热情。但我约了两次，都说最近忙，也没有提其他时间。我还要继续约吗？”

**关系罗盘：**

“先把聊天和见面分开看。对方愿意回复，但目前还没有一起安排见面的行动。

两次没约成、没有提出替代时间，是值得留意的线索。至于是确实忙、还在犹豫，还是没有见面意愿，现在的信息不够确定。

如果你已经把邀约说清楚了，这次可以把安排交给对方：

**‘好，你有空想约的时候叫我。’**

接下来看看对方会不会主动提出具体时间。你也可以先想想，自己愿意在这种不确定里投入多久。”

## 每段关系，都有自己的上下文

如果你正在了解 A、B、C，可以分别建立档案。每个对象都有自己的背景、互动时间线、关系罗盘和详细记录。

```text
你：为小 A 建立档案。我们上个月在朋友聚会上认识。
你：记录今天和小 B 的见面……
你：回顾小 C 最近一个月的互动，看看哪些变化有依据。
```

**讨论 A 时，只读取 A 的相关记录；更新 B，不改动 A 和 C 的档案。** 对象不明确时先确认。只有你主动要求比较时，才一起读取指定对象的资料。

保存的是实际文件，后续可以查看、纠正或删除：

```text
compass-data/
├── index.json                 # 昵称与独立对象 ID 的对应关系
└── people/
    ├── p-<对象 A 的 ID>/
    │   ├── profile.md         # 背景与期待
    │   ├── config.md          # 偏好
    │   ├── timeline.md        # 互动时间线
    │   ├── compass.md         # 当前状态及判断依据
    │   └── sessions/          # 每次记录的事实、推测、建议和后续
    ├── p-<对象 B 的 ID>/
    └── p-<对象 C 的 ID>/
```

你说“记录”“保存”“更新罗盘”或明确要求建档时，才写入文件。普通咨询不自动建档。保存后会读回核对，并告诉你文件位置；后续反馈会关联到原来的事件。

跨会话继续使用，需要让 AI 助手能访问同一个数据目录，并指明讨论哪个对象。隔离依靠独立目录与读取规则实现，不是加密或操作系统权限隔离。

## 开始使用

关系罗盘需要在能够读取 Skill 及其参考文件的 AI 助手中运行。使用独立档案功能，还需要本地文件读写能力。

将下面这段话交给支持本地 Skill 的 AI 助手：

```text
请从 https://github.com/Minggnim-jpg/relationship-compass 下载关系罗盘，
按当前工具的 Skill 安装规则安装为 compass，保留 SKILL.md、agents/ 和 references/ 的结构。
如果已有同名 Skill，先展示差异，不覆盖已有配置或个人数据。
```

也可以下载仓库，把完整的技能文件放入宿主的 `compass` 技能目录。具体位置与加载方式以宿主说明为准。此仓库是 Skill 指令与参考资料，不是独立运行的聊天应用。

安装并加载 `compass` 后，可以从任意一个具体问题开始：

```text
请使用关系罗盘，帮我分析这段互动。
背景是……我的目标是……下面是对话……
```

```text
请使用关系罗盘，帮我回这句话。
我想表达……语气自然一点，不要替我承诺我做不到的事。
```

```text
请为小 A 建立独立档案，把资料保存到我指定的数据目录。
先记录这些背景……
```

不必一次填完所有资料。先讲清楚眼前的问题，有必要时再补充背景。

英文 README 可用于了解与上手；核心 Skill 和大部分参考资料目前是中文，可要求模型用英文回答。

分析框架、表达参考和记录规则全部随 Skill 提供，无需连接外部知识库或配置额外服务。仍需使用具备相应能力的 AI 助手；档案留存需要文件读写权限。

## 数据与隐私

- 可以使用化名；只提供分析所需的对话和背景。
- 档案保存在你指定的位置，默认是当前工作目录下的 `compass-data/`，与 Skill 源文件分开。
- 本地保存不代表完全离线：被读取的内容可能进入 AI 助手的模型请求，具体取决于你使用的平台与服务。
- 个人档案和聊天原文不应进入公开仓库，也不要直接贴进 Issue。
- 本项目不自动监听聊天软件，不代替你发送消息。

## 当前验证范围

已用三个虚构对象验证建档、保存与读回，并检查了仅更新 B 时 A、C 的文件保持不变。这个结果验证了该次文件工作流，不代表所有模型、宿主和长期使用场景都已通过测试。

关系罗盘提供关系分析和表达建议，不承诺读懂他人的真实心理或保证关系结果。遇到明确拒绝时尊重边界；分析不能代替双方真实沟通。
